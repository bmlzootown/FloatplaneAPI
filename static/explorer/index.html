REST auth (Keycloak access token)

Modern third-party REST clients use Authorization: Bearer <access_token> from Keycloak — not cookies. Token stays in localStorage on this device — never commit it. Copy curl is the reliable try path; live browser Send may still fail on CORS.

OpenAPI in this repo still documents only CookieAuth (sails.sid). The explorer surfaces Bearer for REST try-it because current Floatplane clients send Bearer tokens; updating the OpenAPI security scheme is a separate docs task.

Chat / Socket.IO only — sails.sid cookie (legacy for REST)

sails.sid is still used for livestream chat / AsyncAPI Socket.IO authentication. It is not the modern third-party REST auth path and is not attached to Explorer REST curl or Send.
